# Personal-Notes-App

A full-stack notes application for managing personal notes with a clean, intuitive interface.

## Tech Stack
- **Frontend:** Angular, TypeScript, HTML/CSS
- **Backend:** .NET Core, C#
- **Database:** SQL Server

## Features (Phase 1)
- Create, read, update, and delete notes
- Simple, clean UI
- Timestamps for created/modified dates
